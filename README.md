# uGroup Presenter downloads

[Download uGroupPresenter-Setup.exe](https://github.com/KonradTheron/uGroup-Presenter-Releases/releases/latest/download/uGroupPresenter-Setup.exe)

For Windows 11 x64. Download and run this reusable installer to install uGroup Presenter or update your existing installation. When you already have the latest version, it offers **Open Presenter**. Close Presenter before installing an update. Your media library and settings are retained, and the same shortcuts and app registration are used.

The installed app also checks for updates and shows **Update** and **Later** when a newer version is available. Stop the presentation before updating. Downloading and installing an update requires internet access; normal presentations and the local-network web remote work offline.

For installation without internet access on the destination computer, download the full `uGroupPresenter-<version>-win-x64-Package.exe` from the [latest release](https://github.com/KonradTheron/uGroup-Presenter-Releases/releases/latest) on another computer and copy it over. SHA-256 files are included alongside the downloads. Windows may show an unknown-publisher warning because these binaries are not yet code-signed.

This public repository contains installer downloads, update metadata and release notes. Application source is maintained in a separate private repository. No GitHub account is needed to download or run Presenter.
